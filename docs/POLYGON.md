# POLYGON

Development: Amoy chain 80002, gas token POL, eip155:80002.
Production config: Mainnet 137 — payments remain off until `MAINNET_PAYMENTS=true`.

RPC: set `POLYGON_AMOY_RPC_URL`. Public RPCs are rate-limited.

USDT: leave `POLYGON_AMOY_USDT_CONTRACT` empty until you copy the address from a source you trust (explorer / issuer docs). This repo does not invent addresses.
